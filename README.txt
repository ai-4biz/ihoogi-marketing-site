iHoogi — מיני-אתר שיווקי (עמוד אחד, דו-לשוני עברית/אנגלית)
==========================================================

הרצה מקומית
-----------
נכנסים לתיקייה ומריצים שרת סטטי פשוט:
    python3 -m http.server 8080
ואז פותחים בדפדפן:  http://localhost:8080

מבנה
----
index.html            — כל האתר בקובץ אחד (HTML + CSS + JS, ללא תלויות חיצוניות מלבד Google Fonts)
assets/img/           — תמונות ולוגו
assets/media/         — סרטונים + poster

מתג שפה (עברית / אנגלית)
------------------------
בכותרת יש כפתור "EN / עב". לחיצה מחליפה את כל הטקסטים ואת כיווניות הדף (RTL⇄LTR).
ברירת המחדל: עברית. הבחירה נשמרת בדפדפן של המשתמש.
כל הטקסטים מנוהלים במילון I18N בתחתית ה-JS שבתוך index.html — שם עורכים/מוסיפים ניסוחים.

* שימו לב: טקסט שמוטבע *בתוך התמונות והסרטונים* (למשל הכיתוב על התמונה של הינשוף,
  והממשק בצילומי המסך) נשאר בעברית גם במצב אנגלית — כי אלה נכסים אמיתיים.
  אם רוצים אתר אנגלי "נקי", צריך להחליף את קובצי התמונה/וידאו בגרסאות אנגלית.

החלפת הלוגו הרשמי
------------------
הלוגו הנוכחי חולץ מהחומרים שלך. להחלפה בקובץ הרשמי:
  • החליפו את  assets/img/ihoogi_logo.png  בקובץ הרשמי (PNG שקוף מומלץ, או SVG).
  • אם מעלים SVG: שמרו כ- assets/img/ihoogi_logo.svg והחליפו בקובץ index.html את כל
    המופעים של  ihoogi_logo.png  ל-  ihoogi_logo.svg  (מופיע ב-header, בלולאה, בסיפור ובפוטר).
  • גובה הלוגו נשלט ב-CSS (למשל .brand img{height:34px}) — SVG יתאים אוטומטית.

כתובות (הרשמה / כניסה / דמו / צור-קשר)
--------------------------------------
בתחתית ה-JS יש אובייקט SITE_CONFIG. החליפו את ה-"#" בכתובות האמיתיות:
    TRY_IHOOGI_URL, LOGIN_URL, REQUEST_DEMO_URL, CONTACT
(למשל CONTACT: "mailto:hello@ihoogi.com" או קישור וואטסאפ).

פרסום זמני (בלי לגעת בדומיין / בפרודקשן)
----------------------------------------
גוררים את התיקייה כולה ל-Netlify Drop  (https://app.netlify.com/drop)
או ל-Cloudflare Pages / Vercel / GitHub Pages — ומקבלים כתובת חינמית.
הסרטונים כבר דחוסים לווב (הכבד ירד מ-162MB ל-~10MB).

נבנה כתצוגה עצמאית. שום דבר לא מוזג/נפרס למערכת iHoogi.
